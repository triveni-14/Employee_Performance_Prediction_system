# 📊 Employee Performance Prediction System

## 📌 Project Overview

The **Employee Performance Prediction System** is a machine learning project developed to analyze employee data and predict employee performance levels.

The project focuses on data preprocessing, exploratory data analysis, feature engineering, model building, and performance evaluation using HR analytics data.

---

## 🎯 Objectives

- Analyze employee performance-related factors.
- Clean and preprocess the HR dataset.
- Identify patterns and relationships in employee data.
- Create a performance index based on important employee factors.
- Classify employees into performance categories.
- Compare different machine learning models and scaling techniques.

---

## 📂 Dataset

The dataset contains employee-related information such as:

- Department
- Region
- Education
- Gender
- Recruitment Channel
- Number of Trainings
- Age
- Previous Year Rating
- Length of Service
- KPIs Met >80%
- Awards Won
- Average Training Score

---

## 🔧 Data Preparation

The following preprocessing steps were performed:

- Handled missing values.
- Checked and removed duplicate records.
- Converted relevant columns into appropriate data types.
- Dropped the `employee_id` column as it was not useful for prediction.
- Performed exploratory data analysis.
- Created a performance index using employee performance factors.

---

## 📊 Exploratory Data Analysis

EDA was performed to understand:

- Employee distribution across departments.
- Gender distribution.
- Training patterns.
- Previous year ratings.
- Average training scores.
- Relationship between employee factors and performance.

Visualizations were created using **Matplotlib** and **Seaborn**.

---

## 🤖 Machine Learning

The following machine learning models were compared:

- XGBoost
- CatBoost
- LightGBM

Different scaling techniques were also evaluated:

- StandardScaler
- MinMaxScaler
- RobustScaler
- MaxAbsScaler

---

## 📈 Model Evaluation

Models were evaluated using:

- Accuracy
- Training vs Testing Accuracy
- Overfitting and Underfitting Analysis

The models and scaling techniques were compared to understand their performance on the employee dataset.
